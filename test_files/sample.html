Docling Document Converter

Sobre o Projeto

O Docling Converter é uma aplicação moderna desenvolvida em Python que permite converter diversos formatos de documentos de forma simples e eficiente.

Principais Recursos

📄 Múltiplos Formatos

Suporte para PDF, DOCX, TXT, MD, HTML e RTF

🎨 Interface Moderna

Design intuitivo com tema escuro e componentes modernos

⚡ Alto Desempenho

Conversão rápida usando PyTorch e machine learning

Como Usar

  1. Selecione um arquivo para conversão
  2. Escolha o formato de saída desejado
  3. Clique em "Convert Document"
  4. Salve o resultado

Desenvolvido com: Python, Tkinter, Docling

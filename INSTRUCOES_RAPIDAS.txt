╔══════════════════════════════════════════════════════════════╗
║              COMO BAIXAR E EXECUTAR (RÁPIDO)                 ║
╚══════════════════════════════════════════════════════════════╝

PASSO 1: Baixar
━━━━━━━━━━━━━━━
Opção A (Com Git):
  git clone https://github.com/ma-serra/Docling---Conversor-de-Documentos-Tkinter-.git

Opção B (Sem Git):
  1. Acesse: https://github.com/ma-serra/Docling---Conversor-de-Documentos-Tkinter-
  2. Clique no botão verde "Code"
  3. Clique em "Download ZIP"
  4. Extraia o arquivo ZIP

PASSO 2: Entrar na pasta
━━━━━━━━━━━━━━━━━━━━━━━━
  cd Docling---Conversor-de-Documentos-Tkinter-

PASSO 3: Instalar dependências
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  pip install beautifulsoup4 lxml

PASSO 4: Executar!
━━━━━━━━━━━━━━━━━
  python app_legal.py

╔══════════════════════════════════════════════════════════════╗
║                    VERIFICAR SE ESTÁ CERTO                   ║
╚══════════════════════════════════════════════════════════════╝

Depois de entrar na pasta, liste os arquivos:

  ls            (Mac/Linux)
  dir           (Windows)

Você deve ver:
  ✓ app_legal.py
  ✓ template_manager.py
  ✓ templates/
  ✓ GUIA_USO.md

Se vir esses arquivos, está no lugar certo!
